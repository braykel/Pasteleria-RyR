# Pastelería R & R 🍰

Simulador de compras en una pastelería con registro en archivo.

## 🚀 Funcionalidades
- Selección de tortas y bebidas.
- Control de dinero y vuelto.
- Registro automático en `registros.txt`.

## 📂 Archivos
- `pasteleria.py` → Código principal.
- `registros.txt` → Historial de compras.
- Otros archivos de práctica (`clase1.py`, `ejercicio.py`, etc.).

## ▶️ Ejecución
Clona el repositorio y ejecuta:

```bash
python pasteleria.py
